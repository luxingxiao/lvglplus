# 通用扇区渲染与公开示例清理（2026-10-16）

本轮将应用级示例从 examples 及版本管理中删除，已有本地副本移入 Git 忽略的 `.local-validation/`。公共测试与 CI 改用从零编写的 `tests/fixtures/graphics` 几何契约夹具，不依赖本地应用、字库或应用截图。删除当前版本文件不会自动删除既有 Git 提交、历史分支或已下载副本；本轮没有重写远端历史。

## 实现

- sector 以 A8 覆盖缓存替代 5° 三角形色阶。
- 四点覆盖采样处理圆弧和角向边缘；连续角向透明度、整数衰减指数、径向透明度和百分比内圈。
- rasterSize 限制缓存尺寸；旋转/移动/颜色/整体透明度复用覆盖缓存。
- 数学库在对角线半透明度边界存在极小差异，透明度先量化到 1e-7 再转为 8 位，保留精确三路径比较。
- 核心 C99 MVVM 不依赖 LVGL；所有新增绘制逻辑位于渲染适配器，无应用自定义 C 控件。
