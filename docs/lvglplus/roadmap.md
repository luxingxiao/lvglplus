源码实现、自动化测试、宿主集成和真实硬件验收是不同状态。下面按原计划追踪，不以目录或接口代替可运行能力，也不把当前代码称为 LVGL Pro 的无损兼容实现。

| --- | --- | --- | --- |
| P0 | Apache 2.0、独立 XML/IR/API、架构与贡献约定、Pro 研究保留 | 编译与许可文件检查 | 社区治理、商标与长期维护 |
| P1 | XML、组件/参数/slot、布局/样式、IR、C/包、真实 LVGL/WASM、CLI/runner | 原生/WASM/生成 C 精确一致；视觉基线 | 扩展 LVGL 控件覆盖；当前 8 类基础控件与 custom |
| P2 | 类型化模型、共享 VM、绑定/命令/质量/队列、模拟/回放、DBC、CAN/FD、录制 | C 内存/线程测试、DBC、已有 Linux vcan 测试、录制回放 | 最终版本 Linux vcan 复跑、厂商总线与真实收发器 |

## 对标能力

| 能力 | Plus 当前实现与边界 |
| --- | --- |
| XML / AI Coding / 版本管理 | 独立语言，源位置诊断，CLI 与 MCP；不读取 Pro 工程 |
| 实时预览 | C/WASM；重建视图并保留兼容 Model，错误保留有效画面 |
| C 生产代码 | 静态 schema + SDK；无需 XML/二进制解析器 |
| 可复用组件 | 参数、默认值、slot、显式填充和模板编辑 |
| MVVM / 数据接入 | 类型/派生值/命令/双向/质量；数据适配器不操作 LVGL |
| 可视化设计 | 基础控件工具箱、拖放/重排、属性/绑定/事件/动画；复杂设计交互继续扩展 |
| 多语言 / 动画 | UTF-8 key/locale，注册 C 字库；四类属性与两种插值路径 |
| Figma | 独立 Plugin API 导出和保护用户文件的导入器，宿主未验收 |
| Viewer | 纯静态、真实 LVGL，可自托管；设备连接/文件写入留在本地服务 |
| 资源预算 | 包体/PNG/像素 buffer 估算；非峰值内存测量 |
| 扩展控件 | 注册 C 工厂、属性回调、数据绑定；C 变更需显式重编译 |
| UI 自动化 | 模型断言、视觉基线、真实输入、一致性与 MCP；独立 XML 测试 DSL 待扩展 |
| 发布 | 兼容版本、包校验、生成文件隔离、npm 本地归档和桌面封装源码；不是已签名商店发行版 |

下一步优先级是完成表内剩余验收、扩展复杂设计交互、将 Host A/B 契约落实到选定 MCU 的 Flash/BSP，并为经过真实验证的设备增加兼容矩阵条目。没有指定实际板卡之前不列出虚构的硬件支持名单。

## 通用声明式扩展（2026-10-16）

当前工作树新增 IR v3 / SDK ABI 2：path/polygon/sector/grid、动态几何绑定、旋转缩放/裁剪/渐变、有界集合/重复、数值归约/索引/聚类/fitScale、共享数学 VM、原子动作/数值参数、平面状态机、独立时钟/定时器/版本化快照、语义输入和声明式字库。规范见 [declarative.md](declarative.md)，公共渲染夹具见 `tests/fixtures/graphics`。

应用级示例已移出公开仓库，保留为本地验证。公开 CI 使用独立几何夹具；集合、动作和时钟继续由共享运行时单元测试验证。

集合是固定容量的标量槽位；状态机为平面状态机；多边形不支持自交填充；不提供任意脚本、地图瓦片、任意 SVG 或无限动态列表。设备性能、真实车辆网络和具体 MCU 仍需单独验收。

远端跨系统工具链/核心与 Linux 图形验证、DRM 目标编译已有通过证据，见 [本轮验证记录](verification-declarative.md)。DRM 实屏、设备驱动与具体 MCU 仍未验收；vcan/CAN FD 软件链路亦已在补齐 runner 内核模块后通过，仍不等于真实收发器和车辆验收。

平滑 sector 覆盖缓存、角向/径向衰减、环形内圈与精度预算已实现；属性和内存契约见 [声明式文档](declarative.md)。真实硬件的内存与帧率尚待测量。

公开复杂示例新增 [能源控制台](../../examples/energy-console/README.md)，七类确定性场景验证组合渲染和交互；不作为真实能源系统或硬件适配验收。
