# 能力矩阵与交付路线

此文件区分可运行代码、基础接口和后续产品能力；不把设计稿、空适配器或交叉编译当作交付完成。

| 阶段 | 当前实现 | 尚需后续工作 |
| --- | --- | --- |
| P0 | Apache 2.0、独立规范、架构、贡献约定、研究文档保留、版本锁 | 长期社区治理与商标定位 |
| P1 | XML 编译/组件/slot/布局/样式、IR、C/包、真实 LVGL/WASM、原生 runner、CLI、精确一致性测试 | 更完整控件覆盖、字体转换与代码生成优化 |
| P2 | 类型化模型、共享 C VM、绑定/命令/队列/质量、模拟/回放、cantools C codec、SocketCAN/FD、仪表示例 | 更多 DBC 变体、厂商设备/控制器验证、自动录制体验 |
| P3 | 本地 XML Studio、热更新、Inspector、模型注入、多尺寸 target、PNG 文件资源读取 | 动画、多语言、字库工具、自定义控件插件 ABI、DRM 原生应用模板 |
| P4 | 共同 XML 工程与基础属性编辑 | 完整拖放、组件库面板、可视化事件/动画、Figma 插件、独立静态 Viewer、资源预算 |
| P5 | 可选 C 包加载器、HAL、ARM 编译检查入口 | 设备包更新产品流程、串口/Modbus/MQTT、真实 MCU 移植、桌面封装、MCP、迁移与完整发行体系 |

## 与 LVGL Pro 的功能对标

| 能力 | Plus 当前状态 |
| --- | --- |
| 文本 XML、版本管理、AI 可生成 | 已实现独立语言 |
| 真实引擎即时预览 | 已实现，通过 C/WASM，整视图重建并保留匹配状态 |
| C 导出、自动化 CLI、截图 | 已实现；生产 C 为静态 schema + SDK |
| 可复用组件/API/slot | 已实现创建时参数与插槽 |
| 数据绑定 | 已实现，并增加独立类型化模型与质量/时间元数据 |
| UI 交互测试 | 当前为模型断言、截图、一致性及底层输入接口；完整 XML 交互测试语言待实现 |
| 多目标 | 已实现尺寸切换；按目标分配资源/内存区域未实现 |
| 在线分享 | 本地 Web Studio 可运行；公共托管 Viewer 尚未发布 |
| Figma | 未实现 |
| 动画、多语言完整工作流 | 未实现 |
| 图形设计模式 | 当前 Inspector 可修改直接节点 x/y；不称为完整 Design 模式 |
| AI | 可通过 CLI 验证/生成/截图；专用 MCP 未实现 |

## 后续执行顺序

1. 固化首版 API/测试与发布包，扩展自有资源系统、语言和动画语义。
2. 实现可注册的自定义 C 控件描述与预览重编译，形成资源/代码扩展契约。
3. 基于独立 XML 实现可视化设计命令、撤销重做和组件工具箱。
4. 实现 Figma 标注/导出与生成文件所有权，随后交付静态 Viewer。
5. 扩展设备动态包兼容策略、更多协议插件和经过真实验证的 MCU 示例。
6. 构建 MCP 与桌面发行包，完善迁移和跨平台 release 自动化。

每一步都需要可运行样例与回归测试，不能通过新增占位目录宣布完成。
