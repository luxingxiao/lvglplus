# P3–P5 实现与使用（0.2.0）

这一轮交付将后续阶段的核心模块实现为可运行代码。实现状态与验收状态分别记录，不能将桌面封装源码、Linux DRM 模板或 MCU 交叉编译称为已完成所有平台验收。

## Studio 与生产工程

Studio 的 Design 模式与 XML 使用同一个工程：工具箱支持拖入控件；拖动现有控件改变位置，Shift 拖动改变尺寸，4 px 对齐；对象树拖放可改变父级/顺序。属性、绑定、单/双向、点击命令、动画均写回 XML，并经过同一编译器。撤销/重做保存最多 100 次源文本状态。布局使用 Flex 时，应优先修改 gap、padding 和 grow，避免强制绝对坐标。

组件实例通过 Authored XML node 选择器选中 `<use>`；参数编辑写入实例属性，slot 编辑建立 `<fill>` 中的内容面板。展开后的实例不是单独的源节点，不会偷偷把组件展开结果写回模板。直接修改 XML 同样会进入历史；外部文件变化会保留本地尚未保存的内容。结构编辑保留 DOM 中的注释，但 XML 序列化可能改变空白排版。

资源面板上传/删除工程 `assets/*.png`，拒绝删除当前界面引用的资源。PNG 上传限制 1 MiB 和 4096×4096；编译时检查引用、路径、尺寸和资源总额。预算给出包体、PNG 原文件/解码像素、framebuffer 和 draw buffer 大小，不把这些估算冒充峰值设备内存。命令行 `lvglplus budget <project> --json` 输出相同数据。

### 动画与多语言

```xml
<dashboard version="1" locale="en">
  <translations>
    <locale name="en"><message key="title" value="Instrument"/></locale>
    <locale name="de"><message key="title" value="Instrumente"/></locale>
  </translations>
  <page id="home">
    <text id="title" textKey="title">
      <animate property="x" from="0" to="100" durationMs="1000"
               delayMs="0" repeat="0" easing="ease-in-out"/>
    </text>
  </page>
</dashboard>
```

支持 x/y/opacity/value，线性或 ease-in-out，非负有限重复次数。value 限 bar/slider/arc；动画与同一属性的数据绑定互斥。每次重建视图重新计时；UI 时钟后退会重新开始。C、WASM 和生产生成 C 都由 `sdk/src/ui.c` 按相同 UI 时钟插值。Studio 的 Replay animation 重启动画，Locale 切换调用 `lvp_ui_locale`。每个使用的翻译 key 必须覆盖全部声明语言；最多 16 种语言。译文按 UTF-8 保存，实际字形依赖所选字体。

### 自定义 C 控件与字库

`examples/custom` 演示注册 `lvp_widget_factory`、自定义属性、数值绑定、注册字体、翻译与动画。注册表 ABI 为 1，最多 16 类控件/字体；注册信息须比 UI 活得更久。factory 创建真实 LVGL 对象，其私有内存通过 LVGL delete event 清理。业务模型仍不暴露 LVGL 指针。

```sh
lvglplus build examples/custom --wasm
lvglplus dev examples/custom
lvglplus screenshot examples/custom --at 500 --out custom.png
lvglplus font /path/licensed-font.ttf --out app_font.c --size 28 --symbols '车速0123456789'
```

`native.sources` 列出工程内的 C/C++ 源文件，CLI 显式 build 才编译。用户实现一次 `lvp_register_custom_widgets()`，并在其中调用 `lvp_ui_register_widget` / `lvp_ui_register_font`；字体 C 文件也列入 sources。WASM 产物输出到该工程的 `.lvglplus/runtime`；Studio、Viewer、MCP 会选择该产物。C 修改须重新 build --wasm 并刷新浏览器。本地预览服务不会自动编译/执行工程 C 代码；只使用工具内固定的 JS glue，加上显式编译的项目 WASM，不导入项目中的 JavaScript。自定义 C 不支持额外 EM_JS/Embind 宿主脚本导入。

Linux DRM / evdev 应用与 systemd 样例位于 `examples/ports/linux`。生成目标尺寸必须与显示模式一致，资源相对 WorkingDirectory 读取。配置 `-DLVP_LINUX_DRM=ON -DLVP_UI_DIR=<absolute-generated-dir>`，系统需要 libdrm 开发包与显示权限。该模板未在真实 DRM 屏幕测试。

## 设计导入与静态评审

Figma 插件位于 `tools/figma`，通过官方 Plugin API 独立读取结构、布局、文字与 PNG，导出 Plus 中间数据。使用 `lvglplus import-figma export.json --out generated-design` 导入。导入器检查源数据、生成 XML 的编译结果以及文件所有权；再次导入拒绝覆盖手改生成文件，保留 `extensions/` 中的用户文件。支持范围与损失项见该目录 README；不是任意 Figma 工程的无损转换。

```sh
lvglplus viewer examples/vehicle --out build/review
python3 -m http.server 8000 --directory build/review --bind 127.0.0.1
```

Viewer 是纯静态 HTML/JS/WASM/工程包，所有画面来自真实 LVGL。可注入本地模型、切换语言、操作控件、重播动画和下载 PNG，不需要账号或 Node 后端，不提供设备连接和文件写入。通过普通 HTTP 静态站点自托管，不能依赖 `file://` 的浏览器模块权限。

## 数据插件与录制

`sources.json` 的 `adapters` 注册本地服务数据插件；只有开发者主动选择数据源后才连接。模拟、回放、CAN 和插件共用领域信号，UI XML 不变化。完整配置见 `examples/protocols/sources.json`。

| kind | 已实现范围 |
| --- | --- |
| tcp-json | TCP 流，换行 JSON，分片缓冲与 64 KiB 帧上限 |
| udp-json | 一报文一 JSON；端口与监听地址显式指定 |
| serial-json | Linux/macOS POSIX 设备与 stty 波特率；非阻塞读取，换行 JSON |
| mqtt | MQTT 3.1.1，具体 topic、QoS 0 JSON、心跳、重连；可选 TLS 且校验证书 |
| modbus-tcp | Function 03 只读轮询、MBAP/事务/长度检查、uint16/int16/uint32/float32、比例偏移 |

Modbus 双寄存器按大端字节/字序；不实现厂商 word swap、RTU 或写寄存器。MQTT 不声称支持 QoS 1/2、通配主题或认证管理；私有认证 broker 应由部署网关承接。默认样例只读，不产生车辆控制命令。Windows 可使用网络插件；POSIX 串口不是 Windows 串口驱动。

接收队列上限 256 条，显示 received/decoded/errors/overflow/reconnects；不静默合并命令或告警。错误字段发布 invalid，断线更新 disconnected，时间戳供 C 核心处理超时。服务以 100 ms 调度交接到预览核心。录制按钮将信号、质量和相对时间戳写入 `.lvglplus/recordings/*.jsonl`，有文件大小和积压限制，不覆盖现有录制。切换数据源会结束当前录制；将文件配置为 replay 即可复现。录制服务端接入值，UI 本地双向交互如需录制应显式映射到应用数据层。

## 动态包与设备集成

```sh
lvglplus bundle examples/vehicle --out build/vehicle-bundle
lvglplus verify-bundle build/vehicle-bundle
lvglplus install-bundle build/vehicle-bundle --out build/device-store
lvglplus rollback-bundle build/device-store
```

包目录含 `bundle.json`、`ui.lvpb` 和资源。清单逐文件 SHA-256，记录 XML/IR/SDK/LVGL 兼容信息；二进制封装头检查 ABI、LVGL、长度和 CRC32。C `lvp_bundle_load` 可直接加载，`LVGLPlus::live` 中的 `lvp_ui_replace` 在候选包和视图均成功后切换，失败保持原指针与画面，成功保留兼容 Model 值。静态 C 生产路径不需要链接包加载器或 live 库。

Host 安装器以 A/B 目录和原子 active.json 切换演示设备存储契约，旧槽保留且可校验回滚。MCU 产品需要用自己的擦写、同步、掉电恢复和引导标记实现相同契约；不能把 host rename 的原子性直接套到裸 Flash。资源须先校验、挂载，再调用 UI replace；替换后重新注册应用命令/订阅/适配器。CRC/SHA 用于完整性，不提供发布者认证，远程更新的签名与授权由产品集成层负责。

`examples/ports/cortex-m4/main.c` 是可编译 BSP 集成入口，要求板级提供 display/time/wait/lock，其中模型时钟使用单调递增的 64-bit 毫秒值。ARM 示例禁用 POSIX stdio FS，图片读取由 BSP 注册 LVGL 文件系统提供。已交叉编译 C 核心、LVGL、生成 UI 与示例静态库；没有刷写或验证具体 MCU，也不包含车规/功能安全认证。

## MCP、迁移与桌面封装

`lvglplus mcp <project>` 提供本地 stdio MCP：validate、generate、model_read/write、node_inspect、screenshot、resource_budget。模型与截图由同一 C/WASM 核心执行，模型注入不会发送设备命令。stdout 只输出 JSON-RPC，诊断走 stderr。服务实现 [MCP 2025-06-18](https://modelcontextprotocol.io/specification/2025-06-18)，不依赖付费 AI 服务。

```json
{"mcpServers":{"lvglplus":{"command":"lvglplus","args":["mcp","/absolute/project"]}}}
```

XML/project 保持 v1；本次公共 IR/二进制 UI 升级为 v2，SDK 接受 v1/v2，旧 runtime 不接受 v2 包，避免旧运行时悄然忽略新控件和动画。SDK C ABI 与 bundle ABI 为 1，LVGL 固定 9.5.0。`lvglplus migrate <draft-project> --out new-project` 支持文档化的 Plus draft-0 manifest（view/dataModel/resolutions）到 v1，先验证再输出，不原地覆盖；已为 v1 的工程只验证并报告不变。不做 Pro 格式迁移，未知版本明确拒绝。

Electron 封装使用独立本地服务、sandbox、contextIsolation、禁用 Node 页面集成、拒绝外部页面导航与权限请求。运行 `pnpm --filter @lvglplus/desktop start -- --project=/absolute/project`。`pnpm release:pack` 后可通过 desktop 的 `dist` 脚本打目录包。此环境下载 Electron 二进制失败，未验证启动、签名、macOS notarization、Windows 安装与 Linux AppImage；这些属于发行验收缺项，不能标为已发布产品。
